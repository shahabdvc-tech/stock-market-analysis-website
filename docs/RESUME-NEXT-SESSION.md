# برای ادامه در جلسه بعد

**نام پروژه:** Stock Market Analysis Website  
**مالکیت مفهومی:** محصول مستقل تجاری تحلیل بازار بورس ایران  
**وضعیت ۲۰۲۶-۱۱-۱۸:** تدوین مستندات؛ توسعه و استقرار هنوز شروع نشده است.

## تصمیم‌های به‌یادماندنی
- ساخت سایت حرفه‌ای دارای فضای تحلیل و داشبورد، اولویت بالاتر از اتصال حساب ChatGPT است.
- AI باید فقط توضیح و استدلال روی نتیجه موتور تحلیلی کند؛ فیلترهای عددی مستقل و اقتصادی باشند.
- ابزارهای پایه: فیبوناچی ۰٫۶۱۸، RSI، میانگین‌ها، حجم مشکوک، پول حقیقی، کدال.
- Backend مستقل، سایت وردپرسی و داده Supabase؛ منابع جمع‌آوری دست‌نخورده.
- کاربر از ممنوعیت ارائه API BrsApi به دیگران گفته؛ برای نمایش/تحلیل اشتراکی نیز حتماً استعلام کتبی لازم است.
- قیمت‌های ۲۹۹ و ۵۹۹ هزار تومان و هزینه ۲۵ تا ۴۵ دلار صرفاً سناریو هستند.
- مدل اتصال ChatGPT کاربر از طریق MCP/App در فاز بعد و مشروط به امکانات/مجوزهای رسمی است.
- این مخزن برای مستندات و سپس کد محصول است؛ نباید با مخزن اصلی `shahabdvc-tech/iran-stock-market-system` مخلوط شود.

## اولین اقدامات جلسه بعد
1. پاسخ BrsApi را بررسی کن؛ اگر اجازه نداد، درباره منبع داده مجاز تصمیم بگیر.
2. با اجازه کاربر سلامت و ظرفیت Supabase اصلی را فقط‌خواندنی بررسی کن.
3. بر اساس منابع و ظرفیت، طرح فنی دقیق MVP، صفحات، جداول تجاری و بودجه API را نهایی کن.
4. پس از تأیید، توسعه در همین مخزن جدید آغاز شود.
