# نقشه راه مرحله‌ای

## مرحله صفر: اعتبارسنجی قبل از ساخت محصول عمومی
- [ ] اخذ پاسخ کتبی BrsApi؛ بررسی جایگزین دارای مجوز در صورت منع.
- [ ] بررسی ضوابط قانونی خدمات بورسی و مشاوره سرمایه‌گذاری.
- [ ] بررسی سلامت Supabase: آخرین دریافت موفق، پوشش، حجم، خطا و ظرفیت.
- [ ] تعیین سناریوی MVP و معیارهای اندازه‌گیری.

## مرحله یک: API فقط‌خواندنی و موتور فیلتر
- [ ] تعریف نقش سرویس با حداقل مجوز و امن‌سازی کلیدها.
- [ ] ساخت analysis gateway و کنترل rate/quotas.
- [ ] پیاده‌سازی فیبوناچی، RSI، MA، حجم مشکوک و پول حقیقی.
- [ ] ثبت provenance و زمان داده در هر پاسخ.
- [ ] آزمون محاسبات روی نمونه‌های معتبر.

## مرحله دو: وب‌سایت
- [ ] سایت، عضویت و دسترسی اشتراکی.
- [ ] داشبورد، نمودار و صفحه نماد.
- [ ] پنل پرداخت و گزارش سهمیه.
- [ ] کش و آزمون بار.

## مرحله سه: هوش مصنوعی داخل سایت
- [ ] اتصال API مدل کم‌هزینه با برآورد مصرف.
- [ ] ابزارخوانی محدود به Gateway و پرسش فارسی.
- [ ] سقف ماهانه، توقف بودجه، کنترل صحت پاسخ.
- [ ] پایلوت محدود و اندازه‌گیری هزینه واقعی.

## مرحله چهار: ChatGPT App/MCP
- [ ] طراحی OAuth و دامنه دسترسی.
- [ ] ارائه ابزارهای منتخب با همان Gateway.
- [ ] ارزیابی شرایط انتشار و حساب‌های پشتیبانی‌شده.
- [ ] عرضه عمومی فقط پس از احراز الزامات.

## اصل کنترل تغییر
هیچ عملیاتی روی مخزن یا Supabase اصلی گردآوری داده بدون درخواست صریح انجام نشود. ثبت کد، استقرار و آزمون دریافت واقعی سه مرحله جداگانه‌اند.
