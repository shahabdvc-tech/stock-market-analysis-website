# Stock Market Analysis Website

پروژه مستقل ساخت پلتفرم اشتراکی تحلیل بورس ایران با داشبورد، نمودارها، غربالگرهای تخصصی، اطلاعیه‌های کدال و دستیار تحلیل فارسی.

**وضعیت: طراحی و مستندسازی؛ توسعه و استقرار آغاز نشده است.**

## تصمیم اصلی
- **اولویت نخست:** کاربران در سایت ما با فیلترهای عددی و دستیار AI تحلیل انجام دهند. هوش مصنوعی فقط خروجی موتور محاسباتی را تفسیر می‌کند و مصرفش سهمیه دارد.
- **فاز بعدی:** ارائه اتصال اختیاری به ChatGPT شخصی کاربران از مسیر MCP/App، منوط به شرایط فنی و تأیید انتشار و نوع حساب کاربر.
- هر دو تجربه از یک Analysis Gateway امن و فقط‌خواندنی استفاده می‌کنند.

## مجوزهای لازم
طبق توضیح کاربر، BrsApi واگذاری API به اشخاص ثالث را ممنوع می‌کند. قبل از عرضه عمومی، حتی درباره نمودار، داده ذخیره‌شده و تحلیل‌های مشتق‌شده باید **اجازه کتبی برای استفاده تجاری** اخذ شود. همچنین مقررات مربوط به خدمات تحلیل و مشاوره بازار سرمایه بررسی شود. هیچ دورزدنی از ممنوعیت‌ها مجاز نیست.

## معماری پیشنهادی
WordPress (سایت، عضویت، پرداخت، پنل) → Analysis Gateway (احراز هویت، سهمیه، کش) → موتور فیلترها → Supabase فقط‌خواندنی. دستیار سایت با OpenAI API روی نتایج خلاصه تحلیل کار می‌کند. اتصال MCP در فاز بعد به همان Gateway وصل می‌شود.

**پروژه گردآوری داده موجود نباید تغییر کند:** Supabase با شناسه `cpegszivvrziprirdfjp` و مخزن مرجع `shahabdvc-tech/iran-stock-market-system`. هیچ کرون، تابع دریافت، کلید، سهمیه یا داده اصلی بدون درخواست صریح تغییر داده نمی‌شود.

## قابلیت‌های MVP
- نمای بازار، جستجوی نماد و نمودار قیمت و حجم
- تاریخچه معاملات و حقیقی‌حقوقی و اطلاعیه‌های کدال
- فیلتر فیبوناچی ۰٫۶۱۸، RSI، میانگین متحرک، حجم مشکوک و ورود پول حقیقی
- پنل اشتراک، ثبت مصرف و اعتبار محدود AI
- نمایش تاریخ واقعی آخرین دریافت موفق و میزان پوشش داده
